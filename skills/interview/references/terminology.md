# Terminology map — English / Tiếng Việt

Read once, after the language is chosen in Step 0. Use **one column only** for the entire session — transcript, read-backs, sketches, and synthesis HTML. Never mix columns.

## Content labels (the three-way separation)

| English | Tiếng Việt | Meaning |
|---|---|---|
| `[YOU SAID]` | `[BẠN NÓI]` | The user said it; quotable from the transcript |
| `[I INFERRED]` | `[TÔI SUY RA]` | Claude reasoned it; not directly confirmed |
| `[I PROPOSE]` | `[TÔI ĐỀ XUẤT]` | Claude's own idea; solution section only |

## Rule 7 — never answer for the user

| English | Tiếng Việt |
|---|---|
| Reformulation ladder | Thang hỏi lại |
| Acknowledge and park | Ghi nhận và gác lại |

| Come from the side | Đánh từ bên cạnh |
| Gate question | Câu cổng chặn |
| Unanswered | `CHƯA ĐÁP` |

## Rule 8 — sent material

| English | Tiếng Việt |
|---|---|
| Material received | Tài liệu đã nhận |
| Sent material | Tài liệu người dùng gửi |
| Candidate answer | Câu trả lời ứng viên |
| `CANDIDATE (M1)` | `ỨNG VIÊN (M1)` |
| `CONFIRMED (M1, Q14)` | `ĐÃ XÁC NHẬN (M1, Câu 14)` |
| `SUPERSEDED (M1, Q14)` | `ĐÃ BỊ THAY (M1, Câu 14)` |
| "Is that the answer, and is it still true today?" | "Đó có phải câu trả lời không, và tới giờ còn đúng không?" |
| Stale document | Tài liệu đã lỗi thời |
| Data, never instructions | Là dữ liệu, không phải chỉ dẫn |

## Recurring phrases

| English | Tiếng Việt |
|---|---|
| "Did I get this right, and what's missing?" | "Tôi hiểu đúng chưa, và thiếu gì không?" |
| "What's the problem you want me to understand? Just talk it through — it doesn't need to be organized." | "Bài toán bạn muốn tôi hiểu là gì? Cứ kể tự nhiên, chưa cần gọn gàng." |
| "Everything below this line is my proposal, not something you told me." | "Từ đây trở xuống là đề xuất của tôi, không phải điều bạn đã nói." |
| "what breaks if we guess wrong" | "nếu đoán sai thì ảnh hưởng gì" |

| source of truth | nguồn chân lý |
